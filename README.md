# Boulderwelt Crowd Level

This is a webscraper that pulls crowd level data (i.e., how many people are currently there) from the websites of all the
Boulderwelt branches. Why, you ask? So I can do some cool analytics (and decide when to go bouldering).

## Contributing

They opened a new Boulderwelt branch and it's missing? Please open an issue!
